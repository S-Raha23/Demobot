# DemoBot: show it once

A robot learns any tabletop task from **one phone video**, using Meta's models: Muse Spark watches, SAM 3.1 tracks, Muse Wonder writes and debugs the robot program, a swarm of open-weight Muse Spark agents tries to break it, and Muse Voice and Muse Image complete the loop.

Built for the Meta Global AI Developer Hackathon (Indie track, Push the Frontier), Oct 26 – Nov 4, 2026.

> **Build history.** This repository restarts DemoBot on Oct 31, 2026, porting code (the model gateway, budget ledger, goal predicates, media checks and the PyBullet scene and skills) from the author's first repository of the same event (Oct 27–30, 2026). All code was written during the event.
