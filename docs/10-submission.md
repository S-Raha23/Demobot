## README.md structure (Claude writes it in M14)

1. **Title and tagline:** "DemoBot: show it once. A robot learns any tabletop task from one phone video, using Meta's models."
2. **The hero GIF:** real video crossfading into the 3D twin, ≤ 8 MB.
3. **Live demo link** (HF Space), the **3-minute video** link, and the Try-it page link.
4. **What it does:** the six moments, each with a short GIF or screenshot.
5. **How Meta's models are used:** the model-map table from docs/01, plus measured calls, spend and open-weight share from `results.md`.
6. **Architecture diagram:** Mermaid, stages to models.
7. **Results:** the eval table copied from `eval/results.md`, with its date and SHA.
8. **Run it yourself:** replay mode with no keys (`make demo`); full mode with keys.
9. **Exported skills:** how to run `program.py` on another robot by implementing `skill_api.md`.
10. **Limitations, stated honestly:**
    - simulation only;
    - rigid objects, no stacking;
    - the markers are required;
    - parallax assumptions;
    - cost per skill.
11. **Built during the hackathon:**
    - "All code was written between Oct 26 and Nov 4, 2026. This repository restarts DemoBot on Oct 31, porting tested modules from the author's first repository of the same event (Oct 27–30), which was later deleted."
    - "Built with Claude Code as the coding tool; all AI inside the product runs on Meta's models."
12. **Related work and credits:** SeeDo (arXiv 2410.08792), Code-as-Policies, SAM 3, PyBullet, the Franka Panda URDF (pybullet_data), and the Meta Model API docs.
13. **Licence:** MIT.
